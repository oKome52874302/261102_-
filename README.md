# ミニマム勉強帳

「最低ラインだけでもやる」を続けるための、スマホ向け勉強記録アプリです。

公開ページ: https://okome52874302.github.io/261102_-/

## できること
- **今日**：今日やる1つと最低ライン、⏱ タイマー（一時停止・トラック切替）、参考書ごとの今日のノルマ
- **記録**：週・月のグラフ、先週（先月）の自分との比較、ハンコ帳カレンダー、タイムライン
- **はじめてガイド**：初回起動時に、最初のトラックと参考書をその場で登録（「トラック」タブからもう一度見られる）
- **トラック**：科目・試験の管理、参考書・問題集の登録（期限から1日のノルマを自動計算）、曜日ごとのペース設定、バックアップ

## データの保存先
- 記録はブラウザの localStorage に保存され、このリポジトリやサーバーには送られません。
- 端末間では同期されません。「トラック」タブの **バックアップ → 書き出す / 読み込む** で移せます。
- ブラウザのデータを消すと記録も消えるので、定期的に書き出しておいてください。

## ファイル
- `index.html` … アプリ本体（1ファイル完結）
- `icons/` … アプリアイコン（`icon.svg` が元データ）
- `manifest.webmanifest` … ホーム画面に追加したときの名前・アイコン設定
